 # SPM Calc Lab — Form 4 & Form 5 Additional Mathematics

A free, single-page calculator shortcut reference and interactive answer-checking toolkit for Malaysian Form 4 and Form 5 Additional Mathematics students.

## Run it

Open index.html in a browser. It uses plain HTML, CSS, and JavaScript; no package installation, database, API key, or paid service is required.

## What's included

- A searchable chapter library based on the supplied spm_addmaths_complete_hacks guide.
- Model-specific guidance for Casio ClassWiz EX, ClassWiz CW, and ES Plus families.
- 16 local answer-checking tools, including quadratic equations, inverse/composite functions, AP sums, permutations/combinations, binomial probability, weighted means, regression, coordinate geometry, vectors, polar coordinates, logarithms, definite quadratic integrals, a rational derivative template, 3-variable systems, trigonometric roots, and linear-programming vertex checks.
- Mobile-responsive layout and no backend or external JavaScript libraries.

## Accuracy notes

Examples in the uploaded draft were independently recalculated before publication. For example:
- The supplied four-point regression data gives slope 2.00 and intercept 0.05 (so y = 2x + 0.05).
- The derivative of (3x² − 1)/(2x + 5) at x = 2 is 86/81, approximately 1.061728.
- The definite integral of x² − 2x + 3 from 1 to 4 is 15.
- For v = 3t² − 12t, the roots are t = 0, 4; if v = ds/dt, the displacement change from 0 to 4 is −32. An absolute position cannot be found without an initial position.

Calculator key sequences and feature availability can vary by exact model and regional version. This is an independent student resource, not an official Casio or Ministry of Education product. It is intended for learning and checking; students should follow their teachers' instructions and the rules for their actual examinations.
